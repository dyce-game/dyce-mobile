# Reaction sticker set, prototype (female style anchor)

Twenty-four (two sets of twelve) waist-up reaction stickers of the female style anchor (`assets/avatar-reference/style_anchor_female.png`), AI-generated with Higgsfield. They are 1024px transparent PNGs with a white die-cut border; `webp512/` has app-ready 512px WebP copies.

| File | Use in Dyce |
|---|---|
| `amaka_01_win` | Free/Pool result: you won |
| `amaka_02_gg` | "GG" reaction after any game; rematch prompt |
| `amaka_03_shocked` | Opponent's big move, comeback, last-card call |
| `amaka_04_laughing` | Chat reaction; Doodle Guess funny drawing |
| `amaka_05_thinking` | Waiting for your turn / "thinking…" state |
| `amaka_06_your_move` | "Your turn" push, game card and nudge |
| `amaka_07_sad_loss` | Result: you lost (keep it light) |
| `amaka_08_wave` | Onboarding hello, empty states, friend joined Dyce |
| `amaka_09_pot_win` | Pool payout moment (coin burst) |
| `amaka_10_cheeky` | Taunt reaction in chat |
| `amaka_11_facepalm` | Missed shot, scratch on the 8, misclick |
| `amaka_12_dance` | Level up, streak, badge earned |
| `amaka_13_lets_play` | Game invite card; "Let's play" quick reply |

This is a prototype of guidebook §3.3 ("poses and stickers"). In production, stickers are rendered per user from their own avatar config by the render service, using these 24 poses as the target set. Until then, these can ship as Dyce-branded reactions or be used in store screenshots and marketing. The character is fictional.
